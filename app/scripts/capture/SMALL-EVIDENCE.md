# Bounded mobile structural evidence

The separate `codex/parent-ui-evidence` push target runs
`.github/workflows/arbor-parent-evidence.yml` / `mobile-current-screens`.
Its concurrency group differs from the full sweep. Publishing it must not cancel,
rerun or duplicate an existing full capture. Parent review and authorized publication
are required; this code preparation does not run it.

At 375×812 in EN and HE, current selectors capture Now/home, the persistent Ask
launcher and its mock structured answer/understanding/next sections, Together at
first readiness and three seconds later (with module positions), Journal (`journal`),
Timeline (`timeline`), and mobile More. Twenty planned shots use only the existing local synthetic family.
No obsolete More-answer selector or canonical full sweep is executed.

The browser explicitly models **synthetic online** app state by setting
`navigator.onLine=true` before application scripts. Docker still has no external
network, and every provider remains mock/local. Metadata records both this override
and Chromium's original connectivity. The existing `VITE_HAS_GEMINI_API` display
flag suppresses only the test sandbox notice; it supplies no credential or provider.
There is no injected CSS or removal of real error/sync UI. A failed state retains
diagnostic pixels without being marked reached. Together's two frames are the first
observed ready frame and three seconds later, not proof of pre-hydration timing.

The evidence workflow requests the source fonts. Only its dedicated disposable font-preparation container
fetches the exact Google Fonts URL already in `src/index.css` and the WOFF2 URLs
that response names, with a 120-second total bound, no redirects or credentials,
and strict origin/type/size limits. There are no local font downloads or committed
font binaries. The full sweep retains its default fallback mode.

The font-only container runs no application code; its cache is kept in a local CI image, never pushed. Runtime serves those hash-verified bytes from the disposable cache while Docker
remains network-none. `font-provenance.json` records public URLs, hashes and Chromium
version; `font-evidence.small.json` records loaded faces and sampled actual rendered
glyph fonts for every attempted successful screenshot. Source-font shots have an
`exact` filename only after those checks pass. Failures retain `fonts-unverified`
diagnostic PNGs and stay missing evidence. No silent fallback, font substitution,
CSS rewrite or app-source modification is used. These remain synthetic screenshots,
not evidence of a production session; glyph checks sample rather than prove every pixel.

An eight-minute child deadline terminates its own process group before the twelve-minute
capture-step deadline. Every screen writes JSON immediately. The runner reports only
static stage/screen identifiers and screenshot counts. It copies PNG/JSON artifacts
on success or failure and fails honestly if any planned evidence is missing. Setup and
browser errors never export raw environment, server, seed or browser logs. Runtime
retains Docker network-none, a fixed mock/local environment, no host mounts or secrets,
and no microphone/camera permission or paid/provider/real-family action.

Local verification is source-only: `node --check` for capture scripts, followed by
the installed Vitest executable under the offline-network guard (no npm or package download).
No local browser/server/container was launched during preparation.
