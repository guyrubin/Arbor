# Kept capture and normalized search: additive evidence contract

## Status and scope

This is the source-defined **next Parent batch**, separate from the preceding
confirmed-action release. The new `kept-search-only` scope attempts 29 states in
EN and HE at 375×812 and 1280×800: **116 cells in four shards**. It is selected
only for `codex/parent-capture-search-release` in the existing dedicated workflow.
No push, CI execution, screenshots, visual acceptance or native-Hebrew approval
is implied by the local harness tests.

The previous `confirmed-actions-release` remains **858 cells in 16 shards**,
including 172 base-route cells and the existing four print previews. Its state
manifests are unchanged. `kept-search-release` composes both manifests, requiring
**974 cells in 20 shards** for one exact source SHA/tree. A 116-cell diagnostic
cannot pass as that combined release, nor can older-source artifacts fill gaps.

## Representative states

The authoritative machine-readable manifest is `KEPT_SEARCH_STATES`:

- Capture: blank/ordinary words have no default; chips are optional, keyboard
  reachable and 44 px. Only a complete quote entered into a fresh capture
  defaults to Said. Explicit deselection and First/independent choices survive
  typing. Actual repeated submit, persisted row, receipt and Kept destination
  are checked. Cancel/reopen, required trigger/incident response, optional marker
  retirement and native input constraints are recorded without inventing a new
  field-length cap.
- Lineage: one parent-owned row, one `ai_draft` row and one `unverified` row
  appear through the actual Journal feed and detail. Their existing edit/delete
  affordances remain. Final text Send must carry the reviewed words and factual
  source line to the synthetic sink exactly once, without changing the record.
- Old negative-lineage rows deliberately retain dormant `kept: said` markers.
  Real edit/save-confirm must preserve ID, original date and negative lineage;
  neither confirmation nor new quote punctuation may promote the replacement
  into Kept things. AI/unverified input is explicitly **preloaded fixture data**,
  not proof of a model call, transcription or inference quality.
- Kept: real new parent quotes remain eligible. Cancel/reopen rebuilds review
  text from the saved source. A scoped same-document deletion after opening
  review must make the actual final Send guard reject egress. Repeated stale
  opens cannot create a review or send. This source-freshness assertion belongs
  to the existing Kept reader; it is not attributed to generic Journal sharing.
- Child lifecycle: real close, actual child switcher, sibling view and return
  retire the cancelled editor. Both child stores remain isolated. No forced
  click behind a modal or React/internal-state mutation is used.
- Search: desktop topbar at 1280 and the existing modal at 375, in both languages,
  exercise Hebrew marks/finals, Latin accents/case, preserved punctuation and
  bidi controls. A private result reaches the exact Journal row and detail.
  Marks-only global search does not enumerate private records or public routes;
  the existing Ask-prefill row is never invoked. True-empty public commands keep
  the current three-place labels. Visit and preparation queries select the
  current Appointments and Consult results and wait for actual destinations.
- Local Journal and Learn normalization use real inputs/results. Their existing
  normalized-empty unfiltered semantics are distinct from global private-search
  non-enumeration. The real Learn card opens its current reader/history state.
  No new Kids Mode action, retired route, search route or search UI is added.

The exhaustive pure normalization, extraction clamp, capture lifecycle and
ownership cases remain in the previously reviewed source suites. These rendered
states are representative boundary checks, not a duplicate of every pure case.

## Isolation and timing

The existing Docker runtime, exact transient-font cache, source identities,
network-none guards, synthetic-online browser fixture, API/action deny list,
share sink, screenshots and fail-closed aggregate are reused unchanged. No
provider, credentials, real family, external recipient, font upload, install,
host browser, local typecheck, merge or deployment is introduced.

The corrected Date-only fixture leaves performance, timers, document timeline
and native animation time intact. Distinct typed saves advance only synthetic
Date by one second to preserve the real timestamp-based ID contract. Each route,
child replacement and screenshot dialog waits for the passive native-frame
probe. Failure diagnostics and native-clock observations are retained. Existing
optional post-save extraction can use only the already-mocked offline server;
it is never the source of the preloaded lineage assertions.

## Validation gate

Local checks cover the new source/fixture contract, release aggregate,
confirmed-action carry-forward and interaction harness. They do not execute
Playwright. Before accepting this batch, collect the authorized CI artifacts
for the exact final SHA, verify all 116 required cells and exact-font evidence,
and inspect the real EN/HE PNGs. A missing state, false assertion, wrong identity,
missing PNG, font fallback or partial shard keeps the verdict incomplete.
